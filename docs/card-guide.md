# 操作手册

## 0. 先把 NFC 打开

设置 → 连接与共享 → NFC，确认开关是开的。K50 Ultra 的 NFC 感应区在**摄像头下方、手机背部上半部分**，贴卡时贴这里。

## 1. 路线 A：小米钱包门卡模拟

1. 打开「钱包」
2. 首页找「门卡」/「交通卡·门卡」入口
3. 「添加门卡」→「模拟实体门禁卡」
4. 把门禁卡贴在手机背面 NFC 区域，保持不动 2–3 秒
5. 等结果

判断：

| 结果 | 含义 | 下一步 |
| --- | --- | --- |
| 模拟成功，可以命名保存 | 未加密 MIFARE Classic，UID 和数据都拿到了 | 直接用手机刷，若刷不开见第 3 节 |
| 提示「该卡为加密卡 / 暂不支持模拟」 | 卡是加密 Classic 或 CPU 卡 | 走路线 B 读卡，或直接找物业 |
| 一直读不到、没反应 | 125kHz ID 卡，或者卡贴的位置不对 | 换个位置多试；仍不行就是 ID 卡 |

注意：小米钱包需要登录小米账号；门卡模拟部分机型还要求开启「NFC 安全模块」或在「钱包设置」里同意协议。

## 2. 路线 B：MCT 读卡鉴定

装好 MCT 后：

1. 「读标签」→ 贴卡 → 记下 UID、ATQA、SAK
2. 对照下表判断芯片：

| UID 长度 | SAK | 多半是 |
| --- | --- | --- |
| 4 字节 | `08` | MIFARE Classic 1K |
| 4 字节 | `18` | MIFARE Classic 4K |
| 4 字节 | `09` | MIFARE Classic Mini |
| 7 字节 | `00` | MIFARE Ultralight / NTAG |
| 7 字节 | `20` | DESFire / CPU 卡（ISO-DEP） |
| 7 字节 | `28` | 国产 CPU 卡（ISO-DEP） |
| 读不出 | — | 125kHz ID 卡 |

3. 用「密钥字典」试读：MCT 自带常用密钥（`FFFFFFFFFFFF`、`A0A1A2A3A4A5`、`D3F7D3F7D3F7` 等），逐个扇区试
4. 全部扇区能读 → 「保存 dump」→ 「写标签」到 CUID 卡
5. 有扇区读不出 → 需要 nested/hardnested 攻击。手机上成功率看运气（新机型 NFC 栈时序受限），大概率要上 Proxmark3

## 3. 克隆成功但刷不开

说明卡里的数据不是全部，或者系统校验了别的东西：

- **滚动码**：每次刷卡数据会变，克隆卡只能刷一次
- **CPU 卡伪装成 Classic**：只复制了 UID，真正的认证在 CPU 芯片里
- **门禁系统绑定了卡号+时间/次数**
- **电梯卡 / 梯控**：多数是加密的，且和楼层权限绑定

这几种情况，复制空白卡也解决不了，只能找物业加卡。

## 4. 需要专业设备时

- Proxmark3 Easy（约 ¥150）：能跑 hardnested、能写 magic 卡、能读 125kHz
- PN532 + 电脑（约 ¥60）：便宜但只能做基础读写
- 手机 + OTG 读卡器：部分安卓支持，但折腾

## 5. 记录

每次读卡结果写进 `data/读卡记录.md`，尤其是 UID、SAK、哪些扇区读不出，换卡/换设备时能对照。
