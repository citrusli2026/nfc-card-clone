# Google Play 商店文案（中文）

## 应用名称（30 字符内）
门禁卡助手

## 简短说明（80 字符内）
读原卡、写空白卡、自动比对，三步把门禁卡复制到 UID 可写卡。

## 完整说明（4000 字符内）

门禁卡助手把「复制一张卡」拆成三步，每一步都看得见结果。

**① 读基准卡**
把原卡贴到手机背面，读出 UID、卡型、扇区数和全部数据块。

**② 写复制卡**
把 UID 可写的空白卡贴上去，写入和基准卡一样的数据。

**③ 自动比对**
写完立刻读回，逐字节、逐块、逐扇区密钥核对，直接告诉你「完全一致」还是「有差异」，有差异会指出是哪几个块、哪个扇区的密钥不同。

**为什么值得用**
- 全程离线：不联网、不上传，卡数据只存在你的手机里
- 结果可验证：不是「写完了」就算，而是读回来跟基准卡比对
- 记录可回溯：每次读写都存档，历史记录里能查、能删
- 支持 MIFARE Classic 1K / 4K，自动识别卡型

**适合谁**
- 想给家里的门禁卡做个备份，怕丢了进不了门
- 买了空白卡，想把数据写进去
- 想先看清楚自己那张卡到底是什么类型、加密没有

**关于加密卡**
MIFARE Classic 的加密扇区需要密钥才能读写。本工具内置常见密钥字典，能打开的会打开；打不开的会明确告诉你哪些扇区没读出来，不会假装成功。CPU 卡、DESFire 卡不在支持范围内。

**免责声明**
本工具仅用于复制你本人有权使用的卡。复制他人门禁卡、绕过门禁系统可能违法，也可能违反所在场所的规定。请自行确认你有权这么做。

**隐私**
应用不收集、不上传任何数据。详见隐私政策。
