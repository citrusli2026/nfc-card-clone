# Play Console 填表清单

照着一项项填，不用现想。

## 1. 商店条目（Store listing）

| 字段 | 填什么 |
| --- | --- |
| 应用名称 | 门禁卡助手 / Card Clone（≤30 字符） |
| 简短说明 | 见 `docs/play/store-listing-zh.md` / `-en.md` |
| 完整说明 | 同上 |
| 应用图标 | `docs/play/icon-512.png` |
| 特征图 | `docs/play/feature-1024x500.png` |
| 手机截图 | 4–8 张，见 `docs/play/screenshots/README.md` |
| 应用类别 | 工具（Tools） |
| 标签 | NFC、门禁卡、备份、工具 |
| 联系邮箱 | 你的邮箱 |
| 隐私政策 | 托管后的 URL |
| 默认语言 | 中文（简体）或 English |

## 2. 内容分级（Content rating，IARC 问卷）

- 类别：工具 / 实用程序
- 暴力、性、粗俗语言、毒品、赌博：全选「无」
- 是否含用户生成内容、聊天、社交功能：无
- 是否分享位置：无
- 是否含广告：无
- 是否含内购：无
- 结果通常为「所有人」或「3+」

## 3. 数据安全（Data safety）

| 问题 | 回答 |
| --- | --- |
| 应用是否收集或分享任何必需的用户数据？ | 否 |
| 是否收集位置、个人信息、财务、健康等？ | 否 |
| 数据是否加密传输？ | 不适用（不传输） |
| 是否提供删除数据的方式？ | 应用内「历史记录 → 删除」，或卸载即清除 |
| 是否使用广告 ID？ | 否 |
| 是否有第三方 SDK 收集数据？ | 无（纯离线，无 SDK） |

## 4. 目标受众与内容

- 目标年龄段：18 岁以上（避免 Families 政策）
- 是否面向儿童：否
- 是否含广告：否

## 5. 应用访问（App access）

> 说明给审核员看的内容：

- 无需登录，无账号
- 需要支持 NFC 的手机；无 NFC 的设备仍可安装，界面会提示
- 读取/写入需要实体 MIFARE Classic 卡
- 没有卡时应用停留在待读状态，不会崩溃

## 6. 上传步骤

1. Play Console → 创建应用 → 填名称、语言、类型（应用/免费）
2. 左侧「测试 → 内部测试」→ 创建新版本 → 上传 `dist/card-clone-0.2-play.aab`
3. 填写「发布说明」
4. 完成「应用内容」全部问卷（广告、内容分级、目标受众、数据安全、政府应用、新闻应用等）
5. 添加测试人员邮箱，保存并发布内部测试
6. 通过后按「封闭测试 → 正式版」逐步放量

## 7. 审核风险提示

- 这是「门禁卡复制」类工具，审核可能重点看是否帮助未授权访问
- 已在首启和关于页放免责声明；商店文案避免「破解」「万能」
- 如被拒，先按「政策 → 设备与网络滥用」申诉，说明用途是备份自己的卡、完全离线、需实体卡
- 备选分发：F-Droid、官网 APK
