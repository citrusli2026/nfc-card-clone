# 隐私政策

生效日期：2026-11-07

「门禁卡助手」（以下简称"本应用"）尊重并保护你的隐私。本政策说明本应用如何处理信息。

## 我们收集什么

**不收集任何个人信息。**

- 本应用不联网，没有服务器，不上传任何数据
- 不集成统计、广告、崩溃上报等任何第三方 SDK
- 不申请通讯录、位置、相机、存储等与功能无关的权限

## 本机数据

读卡产生的数据（UID、扇区内容、密钥）只保存在本机的应用私有目录：

`/sdcard/Android/data/dev.dsh.nfc/files/dumps/`

- 只有本应用能读写这个目录
- 你可以随时在「历史记录」里删除单条记录
- 卸载应用会一并删除这些数据
- 应用不提供导出功能，数据不会离开这个目录

## 权限

| 权限 | 用途 |
| --- | --- |
| `android.permission.NFC` | 读取和写入 NFC 卡，这是核心功能 |
| `android.permission.VIBRATE` | 操作完成时的触感反馈 |

## 儿童

本应用不面向儿童，也不收集任何用户数据。

## 变更

如果本政策有变化，会更新本页面并修改生效日期。
